# SMART MESS - Project Archive and Documentation

This repository contains the complete operational archive, documentation, impact data, release metadata, and website exports for the SMART MESS system.

## Directory Structure
- docs/: Architecture, guides, supervisor guides, student support, and jury QA preparation.
- impact/: Impact data CSVs, daily and weekly reports.
- operations/: Deployment checklists, update procedures, and emulator logs.
- release-metadata/: Release notes, QA reports, SHA-256 checksums, and freeze records for versions v9.1.0 through v9.3.0.
- website/: Static export of the SMART MESS Old UI website.
- scripts/: Operational PowerShell scripts.
