==============================
1. ROOT CAUSE VERIFICATION
==============================

Defect:
  Student Feedback → Rate Today's Food → Add Photo → Submit
  → "Internal Server Error"

Root Cause:
  Express.js body parser default limit (100KB) silently rejected
  base64-encoded photo payloads (~1-5MB). The global error handler
  returned a raw HTTP 500 instead of a structured JSON response.

Confirmed By:
  - Direct cURL to production API with photo payload → HTTP 500
  - Express error logs showing PayloadTooLargeError
  - After fix: same request → HTTP 201 with photo_url
