=================================
DEFECT FIXED
=================================

ID: SMESS-921-001
Severity: P1 (Production)
Component: Student Feedback — Photo Upload
Symptom: "Internal Server Error" when submitting feedback with a photo
Root Cause: Express.js default body parser limit (100KB) rejected base64-encoded
             photo payloads (~1-5MB). The global error handler returned a raw
             500 instead of a structured JSON error.

=================================
BACKEND CHANGES (commit 8d623ba)
=================================

1. server.js
   - Increased express.json() limit from default (100KB) to 10MB
   - Increased express.urlencoded() limit to 10MB
   - Hardened global error handler to map:
     * HTTP 413 (Payload Too Large) → user-friendly JSON
     * HTTP 415 (Unsupported Media Type) → user-friendly JSON
     * All other unhandled errors → generic 500 JSON (no stack leak)

2. controllers/feedbackController.js
   - Added explicit photo processing with content-type validation
   - Added status code mapping for 413 and 415 errors
   - Added safe Base64 detection and size guard

3. utils/photoStorage.js
   - Added filesystem write fallback to Data URI encoding
   - Added photo type detection from Base64 header
   - Added explicit error codes for oversized/invalid photos

4. models/Feedback.js
   - Added photo_url field to Feedback schema
